How to Use the AI Study Helper

  1. Get a Free API Key: Open the AI Settings section, follow the 5-step guide to create a free Google Gemini key, and paste it in — it saves only in your browser.
  2. Pick a Tool: Choose Study Helper for homework, Mock Exam for a full practice paper, CSS Foundation for exam-prep writing skills, Improve English for grammar, Upload & Ask for your own notes, or Flashcards for quick revision.
  3. Select Class & Subject: Class 9-10 covers Biology, Physics, Chemistry, Mathematics and Computer Science; Class 11-12 covers Medical, Non-Medical and ICS subjects.

How It Works

This instant AI homework helper and CSS exam prep tool runs entirely on Google's free Gemini API, called directly from your own browser using your own personal API key — the same technology used by paid CSS coaching platforms, now free and private. Study Helper answers are tailored to your selected class and subject with five response modes (Explain, Solve, Summarize, Practice, Quiz). Mock Exam builds a fresh board-format paper with MCQs, short and long questions, and a marking scheme every time you generate one. CSS Foundation runs eleven connected tools — English, Essay Writing, Precis Writing, Vocabulary, General Knowledge, Current Affairs, Pakistan Affairs, Islamiat, Analytical Thinking, Reading Comprehension, and Sentence Correction — each built around real FPSC-style exam patterns.

As a free study tool with no signup and zero server uploads, every calculation and every AI call happens using your own key, with nothing saved anywhere except your own browser's local storage. Tips

Mock Exam and CSS Foundation results are AI-generated practice material, not official past papers — use them to build exam temperament and identify weak areas, not as a substitute for the official FPSC syllabus and past papers. If a tool ever shows an "AI error," double-check that your API key is pasted correctly in AI Settings and that your free Google quota hasn't been used up for the day — it resets every 24 hours.

Frequently Asked Questions

Is this tool really free to use?

Yes. Google's Gemini API has a genuinely free tier with no credit card required, and this tool itself has no cost, no subscription, and no sign-up.

Do I need to create an account?

No sign-up is required. Just paste your own free Gemini API key into the AI Settings section once and start using any tool immediately.

Is my data uploaded or stored anywhere?

No. Nothing is saved on any server. Your API key is stored only in your browser's local storage, and your questions, answers, and uploaded PDFs are never stored — they exist only for the single request you make.

What classes and subjects does it cover?

Class 9 and 10 (Biology, Physics, Chemistry, Mathematics, Computer Science) and Class 11-12 across Medical, Non-Medical and ICS groups (English, Computer Science, Statistics, Economics, Physics, Chemistry, Biology, Mathematics).

How does the Mock Exam generator work?

Select a class and subject and it instantly builds a full board-exam-style paper — 8 MCQs, 7 short questions, and 3 long questions — matching real Pakistani board format, with a complete marking scheme you can reveal any time.

Are these real CSS past papers?

No. All CSS Foundation content — essay topics, precis passages, reading comprehension, and mock questions — is freshly generated by AI in the style of real FPSC papers, so you get unlimited fresh practice material instead of memorizing a fixed set of old papers.

Can I upload my own textbook or notes?

Yes, under Upload & Ask. Upload any PDF (up to about 15MB) and ask a question directly about its content — the file is sent only to the AI for that single answer and is never saved anywhere.

What if I run out of free AI quota for the day?

Google's free tier resets daily. Since you're using your own personal key, your quota is never shared with or used up by other students — only by your own usage.
