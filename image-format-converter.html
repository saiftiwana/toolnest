How It Works

This batch image converter tool loads each image, draws it onto an in-memory canvas at your chosen size and orientation, and re-encodes it as JPG, PNG, or WebP using your browser's native image encoding — the same technology used by browser screenshots and canvas exports, so results are reliable and fast. Because every image is redrawn from scratch during conversion, EXIF metadata like camera details and location data is automatically stripped from the output, which doubles as a simple privacy benefit.

Common Use Cases

A web developer converts a folder of PNG screenshots to WebP to shrink page weight before uploading them to a site. Tips

WebP with quality around 75-85% often produces noticeably smaller files than an equivalent-quality JPG, making it a good default when the destination supports it. When converting many images with different original sizes, percentage scaling keeps each image's proportions consistent relative to its own size, while Fit or Exact dimensions are better when every output needs to match a specific size, like a required upload dimension.

Yes, all combinations are supported — JPG to PNG, JPG to WebP, PNG to JPG, PNG to WebP, WebP to JPG, and WebP to PNG.

Are my images uploaded to a server during conversion?

No, every image is processed locally in your browser using canvas-based re-encoding; nothing is uploaded anywhere.

What happens to transparency when converting to JPG?

Since JPG doesn't support transparency, you choose a background color (white, black, or custom) to fill in behind transparent areas before conversion.

Can I convert multiple images at once?

Yes, upload as many images as you like and click Convert Images to process the whole batch, then download everything together as a ZIP.

Does converting an image remove its metadata?

Yes, because each image is redrawn on a canvas during conversion, EXIF metadata like camera model and location data is automatically stripped from the output.

Will converting to WebP reduce file size?

Often yes, especially compared to PNG, but the actual result depends on the image content and quality setting — the file list shows original and converted size for each image so you can confirm.

Can I resize images while converting them?

Yes, choose to scale by percentage, fit within maximum dimensions while keeping proportions, or set an exact width and height.

What happens if one image in my batch fails to convert?

That single image is marked as failed with an explanation, while the rest of the batch continues converting normally.
