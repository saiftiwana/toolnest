Put a Working Tool on Your Own Page

Every tool on ToolNest can be embedded in your own website with a single iframe. The embedded copy is the real tool, not a screenshot or a link: your visitors compress the image, calculate the EMI or convert the Marla figure without leaving your page. Because these tools process everything in the visitor's own browser, embedding one adds no server load on your side and no privacy obligation either, since no file or figure passes through your hosting or ours. There is no account to create, no API key to manage, no monthly fee, and no watermark. The only thing we ask is that the credit line stays below the frame, which the generated code already includes.

How to Add It to Your Site

Pick the tool above, copy the generated code, and paste it into your page wherever you want the tool to appear. On WordPress use a Custom HTML block rather than the visual editor, because the visual editor strips iframe tags. On Blogger switch the post editor to HTML view before pasting. On Wix, Squarespace or Shopify look for an Embed, Custom Code or HTML block. Static sites and hand-written HTML need nothing special: the snippet is ordinary markup. The frame is set to 100 percent width so it fits whatever column you place it in, and the height is fixed because an iframe cannot resize itself to its content across domains. If the tool looks cramped, choose the taller option rather than letting visitors scroll inside the frame.

What Happens Inside the Frame

The embedded tool behaves exactly as it does here with two deliberate differences. First, the share and embed bar hides itself inside a frame, so your visitors see a clean tool rather than links pointing away from your page. Second, no advertising is requested inside an embedded copy, so your page stays free of ads you did not choose. Everything else works normally: files are read and processed on the visitor's own device, results download straight to them, and nothing is transmitted to ToolNest or to you. That last point is worth understanding clearly, because it means embedding a document or image tool does not make you responsible for handling anyone's files.

Terms of Use

Embedding is free for personal, educational and commercial sites alike, including sites that run their own advertising. Keep the credit link below the frame and leave it as a normal, followable link. Do not modify the tool inside the frame, present it as your own product, or place it behind a paywall. We may change, merge or retire a tool, and an embedded copy will follow those changes automatically; older tool addresses are redirected to their replacements, so an embed rarely breaks outright. Frequently Asked Questions

Is embedding really free?

Yes, for any site including commercial ones. There is no fee, no account, no API key and no usage limit. The only condition is that the credit link below the frame stays in place and remains a normal followable link.

Will an embedded tool slow my page down?

The frame loads separately from your page, so it does not block your own content from rendering. Add loading="lazy" — already included in the generated code — and the tool only loads when a visitor scrolls near it.

Do my visitors' files get uploaded anywhere?

No. The tool runs entirely in the visitor's browser, exactly as it does on ToolNest. Nothing reaches your server or ours, which means embedding a file tool does not make you a data processor for your visitors' documents.

Can I change the height or width?

Yes, edit the width and height values in the code. Width is set to 100 percent so it adapts to your column. Height must be fixed, because a cross-domain iframe cannot measure its own content.

Will ads appear inside the embedded tool?

No. Advertising requests are suppressed inside a frame, so your page stays free of ads you did not place yourself.

What if the tool is updated or renamed?

Your embed follows the update automatically. If a tool is merged into a combined studio, its old address redirects to the replacement, so the frame keeps working.
